## Execution order

**001 → 002 → 003 → 004 → 005 → 006**, one at a time. The plans quote the code
as it will be *after* earlier plans, so running them out of order will trip their
"STOP on drift" checks.

- 001 adds the tokens every other plan uses.
- 002 turns the reveal into a one-shot `translate` animation that removes its classes when done. 003 builds on those rules, and 005 relies on revealed cards no longer replaying.
- 004 can only be verified once 002 has restored the hover lift.
- 006 is independent apart from the tokens and can run any time after 001.

## Audit findings not planned (for later)

- **Reduced-motion is all-or-nothing** (`styles.css:343-347`): the global `transition-duration:.01ms` also removes opacity and colour feedback. It would be better to remove only movement.
- **Stagger depends on scroll speed** (`script.js:45`): the delay uses the observer batch index, not grid column. A per-column `--i` delay would be consistent.
- **Form success message swaps text instantly** (`script.js:136-140`): candidate for a 250ms fade + 4px rise and a check icon.
